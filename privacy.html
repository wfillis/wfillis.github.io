Email Alerts

Privacy policy

Effective 9 October 2026

Who uses this app

Email Alerts is a personal tool. Its only users are its owner and the owner's own Google accounts. It is not offered to the public.

Google data the app accesses and why

PermissionAccountUsed for
gmail.sendOwner's main accountSending the owner scheduled notifications.
gmail.insertOwner's main accountAdding emails released from the owner's holding accounts to the owner's inbox. This permission cannot read mail.
gmail.modifyOwner's two holding accounts onlyReading the messages in each holding inbox so they can be delivered, then archiving them and adding a "Released" label. Nothing is deleted.
openid, userinfo.emailAll three accountsConfirming which account was signed in, so access is never stored against the wrong account.

How data is handled

  • Message content is processed in memory only to deliver it to the owner's own inbox. It is not stored elsewhere, copied to other services, or shown to anyone else.
  • The app keeps Gmail message identifiers as delivery records, so no email is delivered twice. Logs record these identifiers, not message content.
  • Access tokens are kept on the owner's private server in files readable only by the service that uses them. Connections use HTTPS.
  • Data is never sold, shared, used for advertising, or used to train AI models.

Google API Services User Data Policy

Email Alerts' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time from Google Account connections. A withdrawn token can no longer be used.

Contact

Questions about this policy go to the support email address shown on the Google consent screen for Email Alerts.
